# DNLS V4 deposit reader's guide

This folder is the canonical V4 deposit layout for the DNLS study *Differential Nonlinear Robustness of Critical States in Fibonacci and Tribonacci Substitution Chains*.

## Contents

- `code/` contains the simulation and figure-generation entry points.
- `data/` contains the long-time CSV outputs used by the deposit-facing analysis.
- `figures/` contains the numbered deposit PDFs (`fig1`–`fig9`) and the preserved canonical PNGs (`fig_A`–`fig_D`).
- `lean/` mirrors the formal Lean files whose canonical home is `TOTOGT/AXLE`.
- `paper/` contains the deposited paper source/PDF pair plus the companion bibliography placeholder.

## Figure-to-script map

| Deposit asset | Script | Input data |
|---|---|---|
| `fig1_chain_structure.pdf`–`fig5_substitution_tree.pdf` | `code/generate_figures.py` | generated directly from `code/dnls_nbonacci.py` |
| `fig6_d2_natural.pdf`, `fig_A_d2_scaling.png` | `code/paper_figures.py` | repo-root `data/d2_natural_lengths.csv` regenerated by `d2_natural_lengths.py` |
| `fig7_fss_T1e4.pdf`, `fig_B_nstability.png`, `fig_C_inversion.png`, `fig8_ratio_collapse.pdf`, `fig_D_homogenization.png` | `code/paper_figures.py` | repo-root FSS CSV inputs consumed by `fss_analyze.py` |
| `fig9_T1e6_saturation.pdf` | `code/analyze_long_time.py` | `data/ipr_vs_time.csv` |

## Reproduction

From the repository root:

1. `python3 DNLS/code/dnls_nbonacci.py`
2. `python3 DNLS/code/generate_figures.py`
3. `python3 DNLS/code/paper_figures.py`
4. `python3 DNLS/code/analyze_long_time.py`

The PR validation run confirmed that the regenerated PNG intermediates for `fig1`–`fig5`, `fig_A`–`fig_D`, and the long-time analysis outputs matched the existing canonical outputs already tracked elsewhere in the repository.
